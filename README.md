# travel-app

A personal/family travel agent — flights, lodging, and activities merged into one timeline per
trip, with reminders and (later) restaurant/attraction suggestions.

- **PLAN.md** — the spec. Read this first.
- **CLAUDE.md** — project guide and non-negotiables for anyone (human or model) working in this
  repo.

Status: planning stage, nothing implemented yet. See PLAN.md's header for the review step before
Phase 0 starts.
